# Punyakoti Taila — Design System

## Design Philosophy

Create a premium organic ecommerce experience inspired by:
- Indian tradition
- Natural wellness
- Minimal modern UI
- Authentic craftsmanship

- Premium
- Trustworthy
- Organic
- Calm
- Clean
